# 🎓 Day 4 – Teach-the-Tutor: Active Recall Coach

This is my submission for **Day 4 of the Murf AI Voice Agents Challenge – Teach-the-Tutor: Active Recall Coach**.

The project demonstrates an interactive voice-based tutor that helps users **learn, quiz, and teach back** programming concepts using Murf-style voices and browser speech synthesis.

---

## 🚀 Features
- **Three Learning Modes**
  - 🧠 **Learn Mode** – Explains each concept clearly. (Matthew voice style)
  - ❓ **Quiz Mode** – Asks conceptual questions and evaluates answers. (Alicia voice style)
  - 🗣️ **Teach Back Mode** – Lets the user explain the concept and gives feedback. (Ken voice style)
- 🎧 **Voice Interaction** powered by the browser's Speech Synthesis API.
- 📚 **JSON-driven content** for easy updates (`shared-data/day4_tutor_content.json`).
- 💬 Simple and clean UI for interactive learning.
