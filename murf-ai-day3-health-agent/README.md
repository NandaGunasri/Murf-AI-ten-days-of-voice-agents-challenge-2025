# Day 3 – Health & Wellness Voice Companion  

Submission for **Murf AI Voice Agents Challenge (Day 3)**  

This project builds a simple **health and wellness voice companion** that talks with users about their mood, energy, and goals, and saves responses into a JSON file for daily reflections.  

### 🧠 Features  
- Voice-based daily check-ins  
- Stores mood, energy, and goals in `wellness_log.json`  
- Reads past entries to give small, supportive feedback  

### ⚙️ Tech Stack  
HTML, JavaScript (Web Speech API), Python (for JSON persistence)
