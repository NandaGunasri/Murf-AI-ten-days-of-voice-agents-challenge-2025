# 🎙️ murf-ai-day1-voice-agent  
Submission for **Day 1 – Murf AI Voice Agent Challenge**

### 💡 About
A simple web-based voice agent that reads any text aloud using the browser’s **Web Speech API**.  
It was built as part of the **Murf AI Voice Agents Challenge 2025**.

### ⚙️ Tech Stack
- HTML  
- CSS  
- JavaScript  

### 🧠 How to Run
1. Open `index.html` in your browser.  
2. Type your message in the input box.  
3. Click **Speak** — the agent will speak your text aloud. 🔊
